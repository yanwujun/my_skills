## 检索策略

### 按章节/知识点检索
```
用户："什么是ATAM评估方法？"
→ read_file ~/软考教程_第8章_质量属性与评估.txt → search "ATAM"
→ 返回教材原文 + 页码/行号
```

### 按关键词全文搜索
```
用户："给我找关于微服务的内容"
→ search_files pattern="微服务" path=~/ → 在所有教材中搜
→ 返回匹配段落 + 所在章节
```

### 真题检索
```
用户："2015年案例分析考了什么？"
→ search_files pattern="2015" path=真题库目录
→ 返回题目和解析
```

## 出题时的知识验证

出题前必须做两步验证：
1. 从教材中确认知识点准确无误（不要凭记忆出题）
2. 从真题中找类似题型参考，确保难度和格式匹配

## 使用规则
- 出题前先检索，不要凭记忆编题
- 答疑时给出教材原文行号，方便用户追溯
- 遇到教材没有的知识点，标出来源和可信度
