# 《阿雅》漫画项目 — 会话参考

## 项目概况
- 原作：《听闻爱情，十有九悲——阿雅》（70,000字中篇小说）
- 类型：现实主义悲剧 / 苗族少数民族题材 / 爱情
- 背景：1981-2023，云南鱼苗苗寨 → 昆明云南大学 → 文山
- 改编：6话74页漫画

## 已验证的技术栈

### 模型选择
- ❌ Dreamshaper 8 → 中国风苗族题材效果差，面孔偏日系，服饰细节丢失
- ✅ Z-Image-Turbo NVFP4 → 原生中文理解，亚洲面孔，国风/水墨，苗族服饰细节准确

### 分镜规范
- 全篇分镜先出再生成（用户明确要求，不可跳过）
- 每页包含：格数、画面描述、镜头类型、光源、对白、英文提示词、负面提示词、种子
- 格式：单一 `storyboard-full.md` 文件，非每页一个文件

### 项目结构
```
comic/aya/
├── adaptation-report.md
├── storyboard-full.md          # 全篇分镜（先出这个）
├── characters/characters.md    # 人物设定+提示词
├── gen2/                       # Dreamshaper 8 输出（效果差，已弃）
│   ├── chars/                  # 角色参考图
│   ├── pages/                  # 14页原图
│   └── final/                  # 14页加对话
└── zturbo/                     # Z-Image-Turbo 输出（待生成）
    └── pages/
```

## 关键教训
1. **分镜先行**：用户说"分镜提示词你没生成啊"即跳过此步骤的后果
2. **Dreamshaper不行就换**：用户说"效果不是很好"→立刻切Z-Image-Turbo
3. **文件路径规范**：创作内容→D:\项目\个人总结\experience\，非平时处理文件夹
4. **ModelScope下载**：国内用魔搭比hf-mirror快（~18MB/s vs ~0.5MB/s）
