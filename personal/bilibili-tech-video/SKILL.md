# B站科技视频脚本制作

## 触发条件

- 用户说"根据周报写视频文稿"、"做一期视频"、"剪映"、"B站发布"
- 用户提供了技术报告/周报，想转成视频内容

## 前置确认（必须先做）

在写任何文稿前，用 clarify 和用户对齐三件事：

1. **内容风格**：干货盘点 / 深度解读 / 新闻快报 / 吃瓜吐槽
2. **画面形式**：纯画面配音（不露脸）/ 半露脸 / 全程出镜
3. **时长和结构**：建议 8-10 分钟，3 个核心趋势，一条主线串起来

用户身份是 Java 开发，做视频的动机是"分享中学习"，所以视频人设是**普通开发者的学习笔记**，不是 AI 专家。真诚、有困惑、有类比——不装懂。

## 类比原则（关键）

**必须用日常生活类比，禁止使用编程/技术类比。**

用户受众是 B 站泛科技观众，不是开发者。用所有人都能秒懂的场景。

正确示例：
- Agent 记忆 ↔ 换新手机，通讯录没了
- MCP 协议 ↔ 充电线统一 Type-C
- AI 安全 ↔ 找开锁师傅测试智能门锁

错误示例（禁止）：
- Agent 记忆 ↔ Redis 分布式 Session
- MCP 协议 ↔ JDBC 标准接口
- AI 安全 ↔ SonarQube 静态分析

## 文稿结构

每期视频脚本包含以下部分：

### 1. 开场（~1分钟）
- "大家好，我是无问凡，一个普通开发者"
- 用一句话引出本周看点
- 画面：桌面录屏 + GitHub Trending 页面

### 2. 趋势一（~2.5分钟）
- 用生活类比切入
- 展示核心项目截图和 Star 数
- 说明"为什么这个趋势重要"

### 3. 趋势二（~2.5分钟）
- 同上结构
- 注意和前一个趋势的逻辑递进

### 4. 趋势三（~2.5分钟）
- 同上结构

### 5. 总结（~1.5分钟）
- 串起三个趋势的内在逻辑
- 回归"普通人视角"的感悟
- 结尾卡：B站名 + 标签 + 关注引导

### 文稿格式

输出为 Markdown，包含：
- 总览表格（段落/内容/时长/画面风格）
- 每段【画面】提示 + 【配音】文字
- 素材准备清单（表格：素材类型/具体内容/获取方式）
- 剪映制作建议（入题节奏、转场、数字动画、结尾卡）

## 素材准备

能帮用户准备的：
- GitHub 项目截图（浏览器截图，保存到 `素材/` 目录）
- 数据提取（Star 数、项目描述）

用户自己准备的（告知即可）：
- 生活场景素材（剪映素材库直接搜）
- BGM（剪映内置）
- 封面图（Canva 或剪映模板）
