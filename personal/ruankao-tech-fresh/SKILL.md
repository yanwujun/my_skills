# 软考新技术在线出题

软考大纲第10-13章涵盖未来信息综合技术、云原生、层次式架构等，这些内容教材更新慢，需要从线上获取最新动态来出题。

## 线上知识获取策略

### 搜索优先级
1. **中文技术社区**：CSDN、掘金、InfoQ、阿里云开发者
2. **开源项目文档**：Kubernetes、Istio、Spring Cloud 官方文档
3. **云厂商白皮书**：阿里云/AWS/GCP 架构最佳实践
4. **技术标准**：CNCF、OpenTelemetry 等

### 搜索关键词模板
```
软考考点 → 搜索词

云原生架构    → "云原生 架构设计 2026"
微服务        → "微服务 服务网格 2026 best practices"  
边缘计算      → "edge computing 最新进展 2026"
AI/大模型     → "大模型 架构 LLM 推理 2026"
区块链        → "区块链 架构 共识 2026"
DevOps       → "DevOps CI/CD GitOps 2026趋势"
```

## 出题规范

### 获取素材后按软考题型出题：

1. **选择题（综合知识）**
   - 从搜索到的文章中提取核心概念
   - 设置典型混淆选项
   - 格式：4选1，有明确正确答案

2. **案例分析题**
   - 从云厂商真实架构案例改编
   - 设置2-3个子问题
   - 考察：架构选型理由、技术对比、质量属性满足

### 出题模板

```
📡 线上来源：[文章标题/URL]（注明出处）

选择题：
1. [基于线上素材的概念辨析题]
   A. ...

   D. ...

案例分析：
[改编自某云厂商/开源项目的真实架构场景]
Q1. ...

Q3. ...
```

## 时效性标记
- 每道题标注"线上来源"和"获取时间"
- 新技术题标注"教材外考点，建议补充"
- 如果线上内容与教材有冲突，以教材为准并标注差异

## 注意事项
- 只从公开可访问的网页获取，不爬付费内容
- 技术概念要准确，不确定的不出题
- 出题后标注可信度（官方文档 > 技术博客 > 论坛帖子）
