# 科学发现型叙事 — 模板片段与节奏指南

适用于"发现一个颠覆性真相→被学界/社会封杀→最终被承认"类的硬科幻/科学悲剧故事。

## 核心节奏（5章模板）

```
第1章  发现异常        钩子: 数据偏差 → 37次重复验证 → 常数浮现
第2章  暗流涌动        自然界的证据 → 权威的夜间警告
第3章  公开挑战        学术会议现场实验 → 被权威当众否定
第4章  众叛亲离        停职/导师倒下 → 合伙人决定赌上职业生涯
第5章  终极证明        终极实验成功 → 被捕 → N年后真相获承认
```

## 常用套路片段

### 反复验证台词
```
他重新计算了一遍。结果一样。算到第X遍时他开始发抖——不是恐惧，是某种预感。
```

### "偏差率"揭露
```
偏差值：XXX。偏差比例：XX.XX%。
一模一样。
X次独立实验，X种不同方法，全部指向同一个数。
```

### 权威对峙
```
"你会后悔的。"
"真理应该经得起检验。"
```

### 终极实验前夜
```
"如果这次失败了——"
"不会的。它一直在那里。它不会消失。"
```

### 结尾反转
```
在档案室最深处，一份泛黄的手稿——
最后一页有一行字：
「我不恨他们。他们也只是错误的囚徒。」
借阅记录上的签名，是三十年以前的——来自那个当年驳斥他的人。
```

## 关键注意事项

| 元素 | 要求 | 反例 |
|------|------|------|
| 核心常数 | 精确到小数点后 10 位，在文本中重复出现 | "一个很大的数字" |
| 偏差百分比 | 具体量化（如 57.08%） | "偏差很大" |
| 实验细节 | 具体材料+精度+环境参数 | "他用仪器测了一下" |
| 权威的动机 | 不是恶人——他有合理的、悲剧性的立场 | 纯粹的恶人反派 |
| 结局 | 不能是"真相立刻被接受"的童话 | "然后大家都信了，完美大结局" |
| 配角 | 每个配角都应该有自己的弧光和选择 | 工具人角色 |
