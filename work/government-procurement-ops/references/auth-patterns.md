# 常用鉴权模式参考

## 运营方列表接口（queryApplyList）鉴权模式

**来源：** v1.26.2.1 平台运营方监管权限
**接口：** `/xcjmallbase/v1/public/enter/plat-org/queryApplyList`
**用途：** 新功能鉴权设计时作为参考模板

### 鉴权核心逻辑

1. **isAudit 判定：**
   - `isAudit=1`：当前登录单位命中平台运营单位配置，且当前人员命中该单位审核岗
   - 若该单位未配置审核岗 → 该单位人员 `isAudit=1`
   - 其他情况 → `isAudit=0`（前端不展示操作按钮）

2. **查询范围：**
   - 运营方：默认当前平台下全部数据
   - 可通过筛选条件切换平台（跨区县查看）
   - 采购人/供应商：仅当前平台数据

3. **角色权限分层：**
   - 运营方（平台运营单位审核岗）→ 查看 + 操作（审核/导出等跨平台操作）
   - 采购人 → 仅当前平台自己相关数据
   - 供应商 → 仅当前平台自己相关数据

### 在升级文档中的引用写法

```markdown
**鉴权参考：** `/xcjmallbase/v1/public/enter/plat-org/queryApplyList`（v1.26.2.1 已实现的运营方列表接口鉴权模式）
- 查询范围：当前平台下全部记录
- isAudit 判定规则同上
- 角色权限：运营方（全部平台可选）、采购人（仅当前平台）、供应商（仅当前平台）
```
